# Prototipos-FrontEnd

Repositório central para armazenar todos os templates front-end gerados a partir dos sistemas desenvolvidos pela equipe TrensRJ.

## Objetivo

Este repositório tem como objetivo reunir, organizar e versionar todos os templates front-end criados com auxílio do Lovable. Cada template representa a interface de um sistema ou funcionalidade já desenvolvida, servindo como base reutilizável, referência visual e ponto de partida para novas evoluções.

## Fluxo de trabalho

Para subir um novo template front-end proveniente do Lovable para este repositório, siga o fluxo abaixo:

1. **Solicite acesso a um token do GitHub ao administrador**
   - O token é gerado no Github pelo administrador da conta**.
   - Após receber acesso, siga os próximos passos de configuração do token na ferramenta Lovable `TrensRJ/Prototipos-FrontEnd`.

2. **Configurar o token na ferramenta Lovable**
   - No Lovable, conecte a integração com o GitHub utilizando o token gerado.
   - Certifique-se de que a conexão possui acesso à organização **TrensRJ** e ao repositório **Prototipos-FrontEnd**.

3. **Utilizar sempre o repositório correto**
   - Todo template deve ser enviado para:  
     `https://github.com/TrensRJ/Prototipos-FrontEnd`

4. **Criar uma nova branch para cada template**
   - Sempre que for publicar um novo template no GitHub, crie uma nova branch dentro deste repositório.
   - Utilize um nome descritivo e padronizado para a branch, por exemplo: `template/nome-do-sistema` ou `template/login-v2`.
   - Isso mantém o histórico organizado, facilita revisões e evita conflitos com o trabalho de outros colaboradores.

## Estrutura recomendada

Cada branch pode conter os arquivos e pastas gerados pelo Lovable. Mantenha a raiz da branch limpa e com uma estrutura clara, facilitando a identificação do template correspondente.

## Observações

- Não faça commits diretamente na branch `main`.
- Sempre que possível, adicione uma descrição breve no commit explicando qual sistema ou tela foi adicionada.
- Para dúvidas ou ajustes no fluxo, entre em contato com o responsável pela governança dos repositórios.
